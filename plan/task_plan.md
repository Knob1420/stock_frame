# Task Plan: 从 B1 到 B1+ —— 看图经验的历史验证闭环

## Goal
把用户脑中的二级看图规则显式化为可计算特征，在历史 B1 样本上逐条验证有效性，用验证通过的条件合成 B1+，再研究 B1+ 样本的成败路径，最后制定买入/持有/退出规则。

## 核心原则（防跑偏红线）
1. 未验证特征只记录、绝不硬过滤进公式
2. 主观判断不是真值：记录 → 验证 → 纳入/条件化/删除 三选一
3. B1+ 只加有增量价值的条件；每加一条要看样本量与 walk-forward（kdj/report.py 已有 FOLDS）
4. 顺序锁死：验证经验 → B1+ → 研究样本 → 交易策略，不跳级

## 口径决定
- B1（粗筛入口）= 原公式复刻 `layers.baseline_original`（GOOD & J<=15 & |PCT|<=3% & AMP<=7%）——与用户描述的"只约束了 J<15、金叉"一致
- 对照 = 三层默认 `layers.signal(DEFAULT_CFG)`（已含 shrink/depth，本身就是"B1+候选"）
- 池 = 主板白名单 new；数据 = stockdata/indicators parquet（已含 ma/vma/boll 等 19 列，零 qlib 依赖）
- 结局指标（每个特征桶都算）：未来 5/10/20 日收益、上涨概率、MFE、MAE、T+5 成本后收益
- 切片：分年 × 牛熊（沪深300 MA240 标签，data.load_index 已有）
- 板块联动：本地无板块数据，本轮跳过并披露

## Phases
- [x] Phase 1: 建 B1 历史事件库（2026-09-18 完成）
  - 全市场(含创业板/科创板/北交所,剔指数)134 万信号 → `research/out/b1_events.parquet`(+benchmark+基线报告)
  - **结论:B1 原公式无优势**——前向10日超额 −0.52%,含成本 T+5 为负;牛熊皆跑输;详见 plan/notes.md
- [ ] Phase 2a: 案例库 + 窗口特征提取（案例驱动假设生成）
  - 案例录入：`research/cases/cases.csv`，用户只标一个主观维度 look(漂/普)；
    成败由数据自动判：T+1 起 10 日内 max_up≥+8%=hit / min_dn≤−5%=miss / 其余 flat（观察池既定口径）→ 四象限 A漂hit/B漂miss/C普hit/D普miss
  - 特征提取：`research/case_features.py`，T-20~T 窗口特征树（价格/趋势/量能/结构/波动；板块无数据暂缺）
  - 红线：案例只出假设，不做证据（自带事后选择偏差）
- [ ] Phase 2b: 四象限对比分析 → 候选约束（定性表述，不定阈值）
  - 判据：特征在"成功 vs 失败"的区分力，而非"漂亮案例共有"（共有可能只是漂亮图的组成部分）
- [ ] Phase 3: 全量历史验证（裁决阶段，与 2a/2b 强制分离）
  - 候选约束 → 可计算指标 → 在 134 万 B1 事件上分桶比前向结局；阈值由数据扫描定，不拍脑袋
  - 判据：超额 vs 同期无条件基准；分年/牛熊/板块切片稳定性；含成本门槛 ≥+0.5%/10日
  - 三种结论：有效 / 仅特定环境有效 / 无区分力
- [ ] Phase 4: B1+ 合成与样本研究（Phase 3 完成并与用户对齐后才启动）
  - 只纳入增量条件（看相关性防同因子重复）；样本量下限；walk-forward 验证
  - B1+ 全历史样本：典型成功/失败路径、最佳介入位置（立即买 vs 等回踩 vs 等突破）、持有期、失效触发条件
