# research/ —— 离线策略研究模块(AI 策略研究员的底座)

**定位**:parquet 的第三个只读消费者(前两个:scan 每日管道、lookup 聚合统计)。
不进日常链、不改生产模块。回答的核心问题:**现有策略有没有优势、什么条件下有效/失效、为什么**。

## 组成

| 文件 | 职责 |
|---|---|
| `dataset.py` | 一遍全扫白名单,产事件级研究数据集(每历史信号一行:特征×环境×多期限结局×同日基线) |
| `viability.py` | 读数据集出可行性报告(确定性表格+机械结论;AI 解读手工追加 §6) |
| `tests/` | 口径单测(前瞻收益/首触日/episode 去重/基线中位数/e2e) |

## 产物(gitignore,可再生)

- `dataset-<cfg_version>.parquet`(+`.meta.json` 溯源)——约 44 万事件,重建约 15 分钟
- `build.log`

## 跑法

```bash
cd /home/admin/stock_selection
.venv/bin/python research/dataset.py      # 重建数据集(内存 ~700MB 峰值,1.6GB 小心)
.venv/bin/python research/viability.py    # 出 research/viability-<日期>.md
.venv/bin/python -m pytest research/tests -q
```

## 口径(与生产一致)

- 前瞻收益**仓位制**(该股自身 bar 序列第 h 根,停牌照位)——同 replay_outcome/track
- 基线 = 同日**抽样**(每 4 只取 1,内存约束;中位数估计不受影响)白名单横截面中位数
- 结局三判 = 池口径(hit+8%/miss−5%/flat 10日,T+1 起算);信号统计用全量股票
- 研究窗口自 2006-01-01(指数 MA240 预热);`cfg_version` 逐事件盖章

## 已知偏差(报告脚注同)

幸存者偏差(只含在市股票,胜率偏高) / ST 5% 涨停拦不住 / 条件边界系看过数据后所定(6c),格子超额带选择偏差。

## 纪律(防自我强化,详见 spec §三)

度量固定、基线对齐、格子 n≥30 才许说话、探索/确认时间切分、假设登记、前向闭环、案例落地。
**回放数据只产生假设,永远不作换版证据。**
